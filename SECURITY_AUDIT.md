# Uplift v1.3 - Security Hardened & Feature Enhanced

## 🔒 Security Audit Report & Fixes

### Critical Vulnerabilities Fixed:

**1. XSS (Cross-Site Scripting) - FIXED ✅**
- **Issue**: Frontend rendered user-controlled content without proper sanitization
- **Fix**: 
  - Implemented comprehensive HTML sanitization in `src/utils/security.ts`
  - Added `sanitizeHtml()` function for all user input
  - Updated `FeedCard.tsx` to sanitize titles, content, tags, and metadata
  - Server-side sanitization enhanced with additional XSS vector protection

**2. SSRF (Server-Side Request Forgery) - FIXED ✅**
- **Issue**: Image proxy allowed arbitrary HTTP/HTTPS URLs without validation
- **Fix**:
  - Enhanced URL validation to prevent access to private networks
  - Added private IP range detection (localhost, 10.x.x.x, 172.16-31.x.x, 192.168.x.x)
  - Prevented URL scheme bypasses and homograph attacks
  - Added domain allowlist support

**3. Rate Limiting Issues - FIXED ✅**
- **Issue**: Weak rate limiting with IP spoofing vulnerability
- **Fix**:
  - Enhanced rate limiting with token bucket algorithm
  - Added proper header validation and fallback behavior
  - Implemented distributed rate limiting using KV

**4. Missing Security Headers - FIXED ✅**
- **Issue**: No Content-Security-Policy, HSTS, or other security headers
- **Fix**:
  - Implemented comprehensive security headers for all responses:
    - Content-Security-Policy
    - X-Content-Type-Options: nosniff
    - X-Frame-Options: DENY
    - X-XSS-Protection: 1; mode=block
    - Referrer-Policy: strict-origin-when-cross-origin
    - Permissions-Policy
    - Strict-Transport-Security

**5. Input Validation - FIXED ✅**
- **Issue**: Weak validation for URLs, emails, and user input
- **Fix**:
  - Added comprehensive input validation functions
  - Enhanced API key validation
  - Safe JSON parsing with size limits

## 🚀 Setup Instructions

### 1. Clone and Install
```bash
cd uplifting-project
npm install
cd server
npm install
```

### 2. Environment Variables

Create `.env` in `/server` directory:
```env
GROQ_API_KEY=gsk_your_groq_api_key_here
ALLOWED_ORIGINS=https://yourdomain.com,http://localhost:5173
SESSION_SECRET=your_long_random_string_here
VAPID_PUBLIC_KEY=your_vapid_public_key
VAPID_PRIVATE_KEY=your_vapid_private_key
```

### 3. Cloudflare Setup

#### Create D1 Database
```bash
cd server
npx wrangler d1 create uplift-db
```

Add to `wrangler.toml`:
```toml
[[d1_databases]]
binding = "DB"
database_name = "uplift-db"
database_id = "your-database-id-here"
```

#### Initialize Database Tables
```bash
npx wrangler d1 execute uplift-db --local --file=./schema.sql
```

Create `schema.sql`:
```sql
CREATE TABLE IF NOT EXISTS users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  streak INTEGER DEFAULT 0,
  last_visit TEXT,
  level TEXT DEFAULT 'Uplift Explorer',
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS bookmarks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER,
  post_id TEXT,
  title TEXT,
  url TEXT,
  image TEXT,
  created_at TEXT DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS push_subscriptions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER,
  endpoint TEXT,
  p256dh TEXT,
  auth TEXT,
  created_at TEXT DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

#### Generate VAPID Keys
```bash
npm install web-push -g
web-push generate-vapid-keys
```

### 4. Deploy
```bash
# Build frontend
npm run build

# Deploy backend
cd server
npx wrangler deploy
```

1. **Content Security Policy**: Strict CSP with controlled sources
2. **Input Sanitization**: All user inputs sanitized using regex-based patterns
3. **SQL Injection Prevention**: Parameterized queries with D1
4. **XSS Protection**: Comprehensive HTML sanitization
5. **SSRF Protection**: URL whitelisting and private network blocking
6. **Rate Limiting**: Token-based rate limiting with KV
7. **Secure Headers**: All modern security headers
8. **Session Management**: Secure token-based sessions with expiration
9. **Password Security**: SHA-256 hashing with salt
10. **HTTPS Enforcement**: Strict Transport Security
